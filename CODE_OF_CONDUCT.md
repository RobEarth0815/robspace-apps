# Code of Conduct

This repository is a small community for users of the robspace apps. The goal is to make it a useful, welcoming place — so a few ground rules.

## Be kind

- Talk to people the way you'd want to be talked to.
- No personal attacks, no slurs, no discriminatory language. Period.
- Disagreement is fine — disrespect is not.

## Be specific

- "It's broken" tells me nothing. "It crashes when I tap Save after entering a future date in 4Budget on iOS 18.6" is gold.
- Use the issue templates. They exist to make sure I have what I need to help you.
- Search before posting — your question might already have an answer in [Discussions](https://github.com/RobEarth0815/robspace-apps/discussions) or [Issues](https://github.com/RobEarth0815/robspace-apps/issues?q=).

## Be patient

- I'm one person. I aim to respond within a few days, sometimes faster, occasionally slower around App Review cycles or when I'm deep in a release.
- A feature request being declined isn't a rejection of *you*. The apps stay small by design, and "no, because…" is a real answer.

## Privacy

- Don't paste personal data (medication names tied to a real person, real financial figures, health logs). Use placeholders.
- Redact screenshots before posting.
- This repo is public — anything you post is readable by anyone, indexable by search engines, and persistent.

## Enforcement

If someone is being abusive, harassing, or otherwise making this a bad place to be: email me at [support@robspace.de](mailto:support@robspace.de). I'll deal with it — lock threads, delete content, block users as needed. I'd rather lose a contributor than tolerate a toxic one.

## Scope

This Code of Conduct applies inside this GitHub repository: issues, discussions, pull requests, and any associated spaces. It does not extend to the App Store reviews of the apps (Apple owns that channel) or to my personal email.
